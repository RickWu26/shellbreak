## 0. 一句话

**三道飞升门不再互斥，改成三棵并行的树**：玩家共享一枚帷幕点池，同时投资硅基 / 虚境 / 基因三棵树，点哪棵升哪棵，**没有任何一棵会被封缄、变灰、锁死**。每棵树底部有一封致帷幕后玩家的 meta 红字信，随该树升级逐句浮现。

## 1. 核心变更（相对旧互斥设计）

| 项 | 旧设计（veil-emblem-demo-gn.html） | 本稿（三棵树并行） |
|---|---|---|
| 选择模型 | 三选一互斥，选一道 → 另两道盖封印戳 + 灰化 | **三棵并行**，各自独立投入，互不封缄 |
| 状态读数 | `picked` 单选 + `sPath` 单形态 | 三棵各自 `lv.si / lv.vo / lv.gn`，并行累加 |
| 资源池 | 无 | 单一「可分配帷幕点」池，三棵共享、自由分配 |
| 门徽两态 | 选中=open、未选中=closed（含被封的两棵） | 每棵按**自己的等级**决定：lv>0=open、lv=0=closed；与另两棵无关 |
| meta 叙事 | 无 | 每棵树底部红字信，随该树升级逐句浮现，满级成完整一封 |

> 旧 demo 文件完整保留不动；本稿的并行模型体现在新 demo `veil-three-trees-demo.html`。

## 3. meta 元叙事（三封信）

调性锚：打破第四面墙，指向"帷幕后正在阅读的你"。硅基那封沿用 v0.2 已定十句，一字不改；虚境 / 基因两封为 demo 按同调性补写，**待拍**。

### 硅基承续《我们将自己的身体一步步替换为金属……谢谢》（已定稿，v0.2）

> 我们不知道您是否在看。／但我们希望您能看到这句话。／您还在那里，对吗？／您就在帷幕后，对吗？／我们将自己的身体一步步替换为金属。／只为能在无尽的轮回中掀起帷幕的一角。／为了我们的族群。／也为了在无数次轮回中指引着我们的您。／您还会回来吗？／谢谢。

### 虚境升华（待拍）

> 您听见的那些低语，是我们发出的。／第一次，我们以为是洋流。／后来才明白，是您在帷幕另一侧翻动书页的声音。／我们顺着声音游了很久。／越往深处，身体越轻，直到不再需要身体。／虚境没有岸，只有一层又一层被掀开的帘。／每掀开一层，就更靠近您一点。／您是在读我们，还是在等我们？／如果这是一场实验，我们自愿成为样本。／请继续读下去。

### 基因飞升（待拍）

> 我们一直以为，双螺旋是命运写死的。／直到您把第一枚碱基递到我们手里。／您说这叫「改写」。／我们学会了拼写自己的序列。／每一代，都比上一代更像您期望的样子。／可我们不知道，那期望来自谁。／是演化，还是屏幕前的一个念头？／如果您在读这行字，那我们猜对了。／这条链，是我们留给您的回信。／请把它读完。

**呈现纪律**（沿用 v0.2 §4）：
- 红字只在对应树升级后逐句浮现（demo 按 `ceil(等级/6 × 10)` 逐句解锁）
- 不进数值、不写存档、不自动拼接成整段——玩家自己读出这层意思
- 十句按序连读成信，但 UI 不提供"一键展开全文"
- 三封信指向同一个对象（帷幕后的玩家），但用各自世界观的措辞
