## 0. 一句话与六项拍板

**功能仍是树，界面仍是身体**：飞升节点绑鲛人器官位，玩家一处处把器官换成机偶（「插义体」爽点）。这条从 v0.1 继承不变。

**变的**：v0.1 是「两阶 6+4、每部位 1 级、10 个效果」；本稿是「**10 部位自由点、每部位 3 级、30 个效果档 + 10 句 LV3 文案**」。9/10 的效果轴被换掉，是重写，不是加一级。

## 2. 三级命名（本稿新定）

| 级 | 名 | 英文代号 | 语义（咬合 LV3 文案） |
|---|---|---|---|
| LV1 | **接枝** | GRAFT | 机械件初次嫁接到活体，本体仍主导 —— 对应「我们不知道您是否在看」的试探期 |
| LV2 | **置换** | REPLACE | 生物组织被机偶成批换下，功能让位于机械 —— 对应「一步步替换为金属」 |
| LV3 | **归一** | CONVERGE | 该部位彻底硅基化，触及帷幕后的意志 —— 对应「谢谢」的告白 |

理由：三个词都是**渐进式改造**语义，串起来正是 LV3 文案那条暗线（从试探 → 替换 → 告白）。UI 上详情卡显示如「鳃 · 归一」，与「已铆封 / 已消散 / 已封存」的封印态措辞体系一致。

## 4. LV3 红字文案（详情卡底部 · 一封信）

每部位升到 **归一（LV3）** 时，其详情卡底部以红字显示对应一句。十句按鳃→心→胃→鳞→鳍→尾→眼→脑→喉→手顺序，连起来是一封完整的话：

| 部位 | 红字 |
|---|---|
| 鳃 | 我们不知道您是否在看。 |
| 心 | 但我们希望您能看到这句话。 |
| 胃 | 您还在那里，对吗？ |
| 鳞 | 您就在帷幕后，对吗？ |
| 鳍 | 我们将自己的身体一步步替换为金属。 |
| 尾 | 只为能在无尽的轮回中掀起帷幕的一角。 |
| 眼 | 为了我们的族群。 |
| 脑 | 也为了在无数次轮回中指引着我们的您。 |
| 喉 | 您还会回来吗？ |
| 手 | 谢谢。 |

> 呈现纪律：① 单句只在**该部位 LV3** 时显示，不是集齐十件才解锁；② 红字是**氛围彩蛋**，不进数值、不进存档结算；③ 十句按器官位顺序连读成信，但**不在 UI 里自动拼接成整段**——玩家自己收集、自己读出这层含义；④ 文案一字不改（含标点）。

| 尾 LV1/2/3 | `economy.hydroAlloc` 的供给侧 `veilHydroMul`，覆盖**全部六个供给源**（汽轮机 / 高压热机管道 / 核热厂 / 泰坦气云 / 太阳帆 / 洁净三源），与 `govHydroMul`（平等主义）同一覆盖范围 | ✅ |

⚠️ 口径：初始人口是**累加型**（LV3 = +30）；百分比档是**替换型**（取当前级，不叠加，否则会越过 100%）；其余全部为**独立乘区**，不并入既有加法轴（`craftRatio` / `buildSave` / `soldierPact` / `warScaleDamage` / 文化折扣）。
⚠️ 热液产出**不进排放**：`pollutionTurbine` / `pollutionOther` 两处显式 `/ veilHydroMul` 除掉这段乘区。
暖石/铀/石头消耗全部按**等级**算（`turL * hydroWarm`、`fisL * 1000`），不按产出算 ⇒ 同样燃料产出更多是效率提升，
排放不该跟着涨；否则在「水体污染」挑战里，花飞升点买的器官会变成静默惩罚（与既有「星屑树乘区豁免」同一原则）。
⚠️ 器官等级只读 `meta.veil.paths.organ`（跨周目永久），**绝不写进 `s.perk`** —— 那是当局派生表，`freshRun` 会按账本整表覆盖。
