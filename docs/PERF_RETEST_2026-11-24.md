# Shellbreak 离线结算、星图与发行包复测

2026-11-24 在同一台 Apple M1、Chrome 158.0.8127.38 上，对照 Gemini 的本地提交 `4988abe` 和本轮游戏代码 `9790493`。TapTap 构建改动在 `18bc2fd`。全部产物留在本机。

## 离线等待

离线 8 小时的新档，正常 CPU 的补算耗时缩短约 43%，四倍降速时缩短约 55%。纪元七存档在广告余额充足时仍有较长等待。四倍降速下，从打开页面到结算完成的中位数是 **10.26 秒**，上一版为 **11.20 秒**。

| 离线 8 小时的场景 | 上一版补算 | 本轮补算 | 上一版最长回调 | 本轮最长回调 |
| --- | ---: | ---: | ---: | ---: |
| 新档，正常 CPU | 2.86 秒 | 1.63 秒 | 18.0 ms | 13.6 ms |
| 新档，四倍 CPU 降速 | 12.33 秒 | 5.59 秒 | 60.2 ms | 35.7 ms |
| 纪元七，6 小时广告余额，正常 CPU | 2.59 秒 | 2.41 秒 | 21.2 ms | 20.1 ms |
| 纪元七，6 小时广告余额，四倍 CPU 降速 | 10.27 秒 | 9.37 秒 | 53.8 ms | 40.1 ms |

每个版本每格跑三次，前后版交替取样。另测最早基线 `00b5a2a`，新档正常 CPU 的补算回调最长 260.8 ms。补算耗时取三次墙钟中位数，最长回调取三次样本内的最大值。新档沿用上一轮探针，从发起补算计到最后一个补算帧。纪元七用游戏自身策略从新档推进到 136 人、49 项科技、39 项市政，回填 8 小时离线时间后重新打开页面，从首次补算回调计到结算结束，另计从页面导航到结算完成的总等待。6 小时的双倍广告余额使 8 小时离线推进了 14 小时游戏时间。四倍降速是 Chrome 模拟，原反馈玩家的设备和存档尚待实机复验。

每段离线积分复用有效岗位人数，发生死亡退岗时立即重算。暖石临界点只取暖石净速率，并与面板共用计算公式。纪元七开关广告的对照、饥荒、冻伤和污染死亡用例均核对完整周目状态及随机抽取次数。四倍降速新档的三轮内，浏览器另记录到一次 56 ms 长任务，回调列只统计游戏补算回调。

## 断点与星图

在真实浏览器中，8 小时补算推进 32 秒后保存，模拟再离开 10 分钟，读档后又推进 32 秒并第二次重启。第三次启动继续剩余任务，累计推进约 29,400 秒后清除断点。旧版累计值超出单段上限的断点、短于 60 秒再次重启、广告余额扣减、同进程回前台、挑战达成存档和导入接管均有专项断言。破壳挑战的解除和轮回选择在结算报告确认后交还。

普通 Web、TapTap 解包页和小红书正式包均在 Chrome 验证。切离星图、滚出视口、页面进入后台后，采样窗口内的星图绘制均为 0。快速往返五次后，每个显示帧至多执行一次星图动画回调。小红书旧包切离总览两秒仍清屏 120 次，切回卫星视图 1.5 秒却没有绘制。本轮在桌面视口恢复 90 帧，触屏模拟恢复 45 帧。卫星和空间站启停、已选天体及最新进度均随视图正确恢复。

五颗天体完成一轮球面绘制的中位耗时从 0.645 ms 降至 0.195 ms。使用相同纹理和六个角度逐像素比较，30 组 RGBA 输出一致，稳定绘制期间新增的 ImageData 为 0。

## 网络和日常刷新

首屏采用 390 × 844、DPR 2、模拟触屏，清空浏览器缓存和站点存储。使用同一本地静态服务，HTML、JS、CSS、SVG 启用 gzip。页面加载后等待 650 ms，首次手势前统计实际传输且响应体非空的导航与资源，不计 HTTP 头。TapTap 从最终上传 ZIP 真解压后访问。

| --- | ---: | ---: | ---: |
| Web 合包 | 24 / 1,365,173 B | 12 / 948,892 B | 5 → 5 |

随行面板首次打开才构建网格，首屏资源图从 14 张、489,878 B 降至 2 张、73,159 B，打开后 14 张全部解码成功。成就页首访 650 ms 内的图片由 35 张、28,124,120 B 降至 18 张、152,752 B。滚完同样的 35 张后共 319,742 B。TapTap ZIP 内的 42 张缩略图逐一解码并与仓库文件比对通过。

## 三项回归和复测入口

| 用例 | 核查结果 |
| --- | --- |
| 未建工坊的锁定提示 | 旧断言读取未选中面板的 HTML。现同时检查玩家可见的页签锁态与提示、锁定面板的提示文案，及拒绝切页时隐藏 DOM 保持原状。 |
| 没有活动事件时领取 | 事件状态属于当前页面，之前的用例可能留下正在等待领取的事件。现先领取一个确定生成的事件，再次领取必须返回 false，并逐项保持周目状态。 |
| 战争提示的失败与被攻入样式 | 队列最多展示四条。现在分别在对应提示上屏时检查样式，并验证旧提示被挤出后的到期处理。真浏览器复现了旧计时器二次移除节点的 NotFoundError，修复后五条连续入队、到期清空均无页面异常。 |

七组定向回归合计 156/156。单独运行战争套件为 56/59，其余三条文案断言在原始基线同样失败。完整套件通过 1974/2051。余下 77 条在原始基线和 Gemini 版本均已失败，逐条按用例名称核对。本机记录见 `regressions.json` 与 `verified-suite.log`。恢复测试补齐了独立刷新页面的 window 和存储快照。采矿工具用例同时验证矿工产出 ×1.8 和扣除炉耗后的净增量。
